# D06–D10: concreción de F2

Coordinador, 2026-10-06. Base `28bd92ecd424ff11b31e13e4a2ba499cb196a870`. F0/F1 y sus evidencias permanecen históricas. Estas decisiones concretan la futura ejecución; no dicen que F2 esté implementada o publicada. [SDD](../../fases/f2-lectura-markdown.md), [contratos](../../fases/f2-contratos.md).

| ID | Decisión | Prueba, consecuencia y límite |
|---|---|---|
| D06 | Dividir F2 en proyección F2A y negociación F2B, consecutivas. | Reduce el contrato de cada Luna manteniendo un índice único. No solapamiento de archivos; F2B solo empieza sobre A aceptada. El hito de score/publicación exige ambas. |
| D07 | Proyección después de F1+sitemap, config.build.client, y routing compilado en hook antes de packaging. Máximo98 documentos y100 reglas totales; cada patrón≤100 caracteres. | [Probe actual](plataforma.md): orden secuencial efectivo adapter → sitemap → F1 → proyección del Astro instalado; el adapter ya produjo/normalizó config cuando proyección la actualiza. 28 documentos/30 reglas/max84, config efectiva y dry-run. Los límites numéricos vienen del parser Wrangler4.128 y [documentación oficial de assets](https://developers.cloudflare.com/workers/wrangler/configuration/#assets). Fail closed por encima; no `run_worker_first=true`, glob global, upgrade o postbuild. |
| D08 | Documentales servidos directamente con ASSETS Request; handler Astro delegado para resto. | Precisa D01: handler actual `matchStaticAsset` usa URL string y pierde HEAD/If-None-Match. Probe verifica GET/HEAD/ETag propios304 y cruzados200 con Request, sin import circular del índice. F2 prueba todo corpus y matriz; no promociona patch experimental. |
| D09 | Sin caché propia de respuestas documentales. Exterior negociado `private, no-store`, VaryAccept; cache interna ASSETS por HTML/MD distintos. | Precisa D04 y criterio de “caché caliente” del plan: alternancias repetidas en todas las capas activas, comprobar que exterior no almacena variantes, no esperar TTL/purgar una capa deshabilitada. Local solo prueba política/ASSETS, no zona. Preview pública y gate de producción conservados; si zona ignora política, falla gate. [Assets](https://developers.cloudflare.com/workers/static-assets/) tienen cache/fingerprinting interno; no atribuir eso a Cache API ni declarar HIT/MISS no medidos. Coste: documentos canónicos ejecutan Worker y no ofrecen caché exterior compartida en v1, mientras asset interno sigue reutilizable; browser no almacena cuerpo negociado. Fase posterior solo cambia política con necesidad/evidencia y nueva spec. |
| D10 | Perfiles DOM propios y Version URL pública del mismo HEAD. | [Inventario](inventario-editorial.md): 34HTML/28 documentos,6 pilares salud+herramientas, H1 fuera de main y avisos ocultos precisados. [Version URLs](https://developers.cloudflare.com/workers/versions-and-deployments/version-urls/) comparten bindings: solo GET/HEAD documental. Comentario bot PR51 [6002452083](https://github.com/Gunz-cop/CuidaTuPerroViejo/pull/51#issuecomment-6002452083) demuestra que el repo ya emite Commit Preview; esa URL histórica no es la preview de F2. Cada entrega conserva su receipt exacto. No instalar Workers Previews/actualizar4.128 ni inventar credenciales. |

Los experimentos fueron realizados por sesiones separadas de Luna6high en worktrees detached; el coordinador no escribió runtime del producto. El patch se conserva como evidencia exploratoria, no como base de implementación. Manifest sella snapshots locales, no certifica CDN. Reproducciones pueden necesitar permiso mínimo de red/IPC del sandbox; una negativa de ese entorno no equivale a caída del evaluador.
